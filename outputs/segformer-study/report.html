SegFormer on synthetic and real underwater images

Replacing half the real training masks with SynTIDE lowered six-class UIIS mean IoU by 2.52 percentage points (paired 95% interval −8.15 to +2.13). The interval includes both a loss and a gain on this benchmark.

With the same replacement, fish IoU changed by +0.35 points on DeepFish and −1.84 points on CoralscapesV2.

Interpret the full UIIS result as an in-domain comparison. 578 of its 691 holdout frames match photographs from the generator’s training sources. The sensitivity analysis below repeats the comparison on the remaining 113 frames. Both external fish tests passed the same similarity screen.

Design and interpretation

Each SegFormer-B0 run started with an ImageNet-pretrained encoder and a fresh semantic head. Real-only training used 3,000 real pairs. Synthetic-only training used 3,000 generated pairs. Mixed training used 1,500 synthetic pairs and 1,500 uiis pairs. Each mixed batch comprised four real and four synthetic images, drawn from subsets of the corresponding single-source training pools. All nine runs used 4,000 AdamW updates of eight images each and the same flip and brightness augmentations. Peak learning rates were 0.00006 for the encoder and 0.0006 for the decoder, with 100 warm-up steps and linear decay. The final checkpoint was scored for each paired seed (17, 29 and 43). The input was fitted and padded to 512 × 512. Evaluation removed padding, restored logits to the original mask dimensions with bilinear interpolation, and selected the highest-scoring class per pixel. The run configurations contain the exact schedule.

The 50/50 split is defined by image count. Over one pass through its 3,000 distinct images, synthetic examples supply 56.52% of valid supervised input pixels. At the 512-pixel input size, all pixels on the synthetic canvases are supervised, compared with 76.93% on the real canvases after letterboxing and removal of ignored regions.

The real-only pool contains 2,225 UIIS scene or perceptual-hash groups among 3,000 distinct files. The mixed pool contains 1,500 such groups among 1,500 real files. Distinct views within the same group can be similar. Matching groups across development and evaluation were excluded from training.

The real training pool has 46 images containing labeled robot pixels. The synthetic pool has 290. Differences reflect the observed source distributions, including class frequency, label quality and scene diversity.

IoU pools pixel confusion counts across images before division. Dice, precision and recall use the same pooled fish counts. Background and ignore pixels are distinct. UIIS background is included when counting false positives and excluded from the six-class mean. Ignore pixels are excluded from every metric. Blank per-image scores indicate undefined denominators.

Intervals use 2,000 paired percentile bootstrap draws. Each draw resamples identical test groups for every condition and seed, pools pixel counts within each run, then averages the three paired seed differences. Draws missing a reference class are omitted for UIIS foreground mIoU. UIIS groups use available near-duplicate clusters or individual images. DeepFish groups are clip prefixes inferred from filenames. CoralscapesV2 groups are dive sites. Its five sites limit the precision of its interval. Seed standard deviations are reported separately in the CSVs. These intervals describe test-set sampling variability conditional on the trained models and selected training pools.

The TIDE generator was trained on the UIIS training split. The 691-image UIIS holdout was reserved in the TIDE paper and is evaluated here after training. The published UIIS fish category also includes other vertebrates, whereas the external sets target fish. Dataset changes can therefore reflect both scene differences and labeling policy. The comparison estimates the effect of replacing selected real labels under a fixed total budget. A benefit from adding synthetic data to a fixed set of real labels would require a separate half-size real-only control.

Manual inspection of selected SynTIDE overlays found an example with part of a sea star labeled as robot (TIDE_011743). This illustrates a possible source of error. Its frequency was not estimated by that inspection.

Result files

Seed scores, class support, per-site scores and bootstrap intervals are saved in metrics/. Each run’s per-image CSV maps the original identifier to its native-resolution indexed PNG in predictions/.
